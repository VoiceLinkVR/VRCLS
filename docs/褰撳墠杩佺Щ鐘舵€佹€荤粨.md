# VRCLS-CSharp 迁移状态总结

**最后更新**: 2025-02-01

## 迁移概览

本项目是将 Python 版本的 VRCLS (VRChat LinguaSync) 重写为 C# .NET 8 WPF 应用程序。目标是获得更好的性能、更低的延迟和更优的用户体验。

### 总体完成度: ~90%

核心功能已完成，热键、命令、TTS、SteamVR Overlay 均已实现。剩余多翻译引擎和自动更新功能。

## 服务器接口契约

### 认证
- `POST /api/login` - 登录获取 access_token
- 后续请求需 `Authorization: Bearer <token>`

### 主要接口
- `POST /api/func/multitranslateToOtherLanguage` - 识别+翻译
  - 表单字段: `sourceLanguage`, `targetLanguage`, `targetLanguage2/3`, `emojiOutput`
  - 文件字段: `file` (audio/opus)

### 音频协议
- 格式: 4 字节大端长度 + Opus 包
- 参数: 16kHz 单声道, 20ms 帧

## 运行指南

### 构建
```bash

```

### 运行 UI
```bash
cd 03.VRCLS.UI
dotnet run
```

### 运行测试
```bash
cd tests/VRCLS.ConsoleTest
dotnet run
```
