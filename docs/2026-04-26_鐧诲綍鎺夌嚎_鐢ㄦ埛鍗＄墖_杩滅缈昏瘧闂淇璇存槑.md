# 2026-04-26 登录掉线、用户卡片与远端翻译问题修复说明

## 范围

本文档记录上一轮针对以下用户反馈完成的修复：

- 官网授权后出现 401 时会掉登录。
- 401 发生时用户信息卡片会被错误状态文本撑得很长，并且视觉上像一片空白。
- 不在本机使用的用户出现“不翻译”，检查日志 `C:\Users\boyqiu001\Downloads\vrcls-20260426 (2).log` 后定位到翻译文本清洗和音频管线取消竞态问题。

当前工作区存在其他早于本次修复的未提交改动。本文只说明本次问题修复相关代码，不把其他已有 UI/配置改动纳入说明。

## 日志分析

### 1. 401 不是一次性失败，而是反复影响识别与账户查询

日志中多次出现：

```text
Recognition API (...) returned 401 for an access token that was already refreshed and rejected.
Recognition API returned 401 after centralized auth retry. content: {"detail":"Not authenticated"}
UserCenter account usage returned 401 ...
```

统计结果：

- `Recognition API .* returned 401`：476 次。
- `/auth/me` 或账户查询在 token 刷新后仍可能返回 401。

原逻辑的问题是：refresh 已经返回了新的 `access_token`，但随后 `/auth/me` 校验失败时会把本地 token/session 当作彻底失效处理，导致用户看起来“掉登录”。这个判断过于激进，因为 refresh 成功说明会话仍可能可恢复，`/auth/me` 只是资料补全接口失败或后端短暂不一致。

### 2. “不翻译”日志里多数不是没有翻译

日志中存在大量翻译结果：

- `添加翻译1`：887 次。
- 未发现 `No enabled translation targets`。

所以目标语言没有被关闭，远端翻译链路也不是整体停掉。

真实问题有两类：

1. 服务端返回的翻译结果带了说明性前缀和空行，例如：

```text
以下是翻译：

“要干架了吗？准备好龟派气功了吗？...”
```

这会在主窗口、历史记录或 OSC 中制造空行，用户会以为没翻译或显示异常。

2. 日志中出现音频管线后台任务异常：

```text
System.ObjectDisposedException: The CancellationTokenSource has been disposed.
Audio pipe backlog is full; dropping frame.
```

延迟任务还在读取 `CancellationTokenSource.Token` 或 `IsCancellationRequested` 时，取消方已经 Dispose 了同一个 CTS，造成未观察后台异常。异常附近又伴随大量丢帧，因此部分语音片段可能没有稳定进入识别/翻译流程。

### 3. 用户卡片变长的原因

用户中心顶部状态徽标直接绑定 `ConnectionStatus`。当 401 或登录失败时，`ConnectionStatus` 可能包含完整错误信息，例如 `连接失败: ...`，而 XAML 中没有宽度限制和裁剪策略，导致状态文本撑开用户信息卡片。视觉上就会变成一条很长、内容稀疏甚至像空白的卡片。

### 1. `BackendAuthService.cs`：refresh 成功但 `/auth/me` 失败时不再清空会话

修改原因：

- refresh 成功返回 `access_token`，说明当前 refresh token 仍有价值。
- `/auth/me` 失败不应立即清空本地 refresh token，否则会把可恢复会话变成强制掉登录。
- 使用本地持久化身份信息补齐 `AuthUserResponse`，让 token 先落盘，后续再恢复资料。

修改代码：

```csharp
var refreshUrl = $"{BackendUrlHelper.BuildV2AuthBaseUrl(_config)}refresh";
try
{
    if (!silentRefresh)
    {
        UpdateState(CreateState(BackendAuthStatus.LoggingIn, accessToken: null));
    }

    using var response = await _httpClient.PostAsJsonAsync(refreshUrl, new { refresh_token = userInfo.RefreshToken }, cancellationToken);
    var raw = await response.Content.ReadAsStringAsync(cancellationToken);
    if (!response.IsSuccessStatusCode)
    {
        var detail = ExtractErrorMessage(raw, response);
        if (ShouldDiscardPersistedWebsiteSession(response.StatusCode, raw))
        {
            ClearTokens(userInfo);
            SaveConfigSnapshot("refresh website session failed");
            _logger.Warning(
                "Website refresh rejected persisted credentials. status={StatusCode}, detail={Detail}. Cleared cached website session.",
                (int)response.StatusCode,
                detail);
        }
        else
        {
            userInfo.AccessToken = string.Empty;
            userInfo.ExpiresAt = null;
            SaveConfigSnapshot("refresh website session failed but refresh token preserved");
            _logger.Warning(
                "Website refresh failed with a non-auth error. status={StatusCode}, detail={Detail}. Preserving refresh token for retry.",
                (int)response.StatusCode,
                detail);
        }

        var failedState = CreateState(
            BackendAuthStatus.Failed,
            $"Website refresh failed: {detail}",
            accessToken: null);
        return silentRefresh && !ShouldDiscardPersistedWebsiteSession(response.StatusCode, raw)
            ? failedState
            : UpdateState(failedState);
    }

    var payload = JsonSerializer.Deserialize<AuthTokenResponse>(raw);
    if (string.IsNullOrWhiteSpace(payload?.AccessToken))
    {
        var failedState = CreateState(
            BackendAuthStatus.Failed,
            "Website refresh response did not return access_token.",
            accessToken: null);
        return silentRefresh ? failedState : UpdateState(failedState);
    }

    try
    {
        payload.User = await FetchCurrentUserAsync(payload.AccessToken.Trim(), cancellationToken).ConfigureAwait(false);
    }
    catch (UnauthorizedAccessException)
    {
        _logger.Warning("Website refresh returned an access token, but /me rejected it. Persisting the refreshed session and deferring profile hydration.");
        payload.User = CreateUserResponseFromPersistedIdentity(userInfo);
    }
    catch (Exception ex)
    {
        _logger.Warning(ex, "Website refresh returned an access token, but /me validation failed. Persisting the refreshed session and deferring profile hydration.");
        payload.User = CreateUserResponseFromPersistedIdentity(userInfo);
    }

    return await ApplyTokenResponseAsync(
        payload,
        BackendAuthMode.WebsiteAuthorized,
        isAnonymous: false,
        cancellationToken,
        allowStoredRefreshTokenFallback: true,
        emitStateChange: !silentRefresh,
        runPostLoginTasks: !silentRefresh);
}
```

新增翻译清洗方法：

```csharp
private static string NormalizeTranslationText(string? text, string source, string field)
{
    var cleaned = NormalizeTranscriptText(text, source, field);
    var stripped = StripTranslationBoilerplate(cleaned);
    if (!string.Equals(cleaned, stripped, StringComparison.Ordinal))
    {
        _logger.Debug(
            "Removed translation boilerplate (Source={Source}, Field={Field}, BeforeLength={BeforeLength}, AfterLength={AfterLength}, Preview={Preview})",
            source,
            field,
            cleaned.Length,
            stripped.Length,
            TrimForDebug(cleaned));
    }

    return stripped;
}

private static string StripTranslationBoilerplate(string text)
{
    if (string.IsNullOrWhiteSpace(text))
    {
        return string.Empty;
    }

    var cleaned = TranslationBoilerplatePrefixPattern.Replace(text.Trim(), string.Empty, 1).Trim();
    if (string.IsNullOrWhiteSpace(cleaned))
    {
        return string.Empty;
    }

    var lines = cleaned.Split('\n')
        .Select(line => line.Trim())
        .Where(line => !string.IsNullOrWhiteSpace(line))
        .ToArray();

    if (lines.Length > 1)
    {
        if (IsTranslationBoilerplateLine(lines[0]))
        {
            return string.Join("\n", lines.Skip(1)).Trim();
        }

        if (lines.Take(lines.Length - 1).Any(IsTranslationBoilerplateLine)
            && TryUnwrapQuotedLine(lines[^1], out var unwrappedLastLine))
        {
            return unwrappedLastLine;
        }
    }

    if (TryUnwrapQuotedLine(cleaned, out var unwrapped))
    {
        return unwrapped;
    }

    return cleaned;
}

private static bool IsTranslationBoilerplateLine(string line)
{
    if (string.IsNullOrWhiteSpace(line))
    {
        return false;
    }

    var normalized = line.Trim();
    if (TranslationBoilerplatePrefixPattern.IsMatch(normalized))
    {
        return true;
    }

    var hasTranslationTerm = normalized.Contains("翻译", StringComparison.Ordinal)
        || normalized.Contains("翻譯", StringComparison.Ordinal)
        || normalized.Contains("译文", StringComparison.Ordinal)
        || normalized.Contains("譯文", StringComparison.Ordinal)
        || normalized.Contains("翻訳", StringComparison.Ordinal)
        || normalized.Contains("訳す", StringComparison.Ordinal)
        || normalized.Contains("訳せ", StringComparison.Ordinal)
        || normalized.Contains("translation", StringComparison.OrdinalIgnoreCase)
        || normalized.Contains("translated text", StringComparison.OrdinalIgnoreCase);
    if (!hasTranslationTerm)
    {
        return false;
    }

    return normalized.Contains("以下", StringComparison.Ordinal)
        || normalized.Contains("下面", StringComparison.Ordinal)
        || normalized.Contains("如下", StringComparison.Ordinal)
        || normalized.Contains("とりあえず", StringComparison.Ordinal)
        || normalized.Contains("以下のよう", StringComparison.Ordinal)
        || normalized.Contains("here", StringComparison.OrdinalIgnoreCase)
        || normalized.Contains("following", StringComparison.OrdinalIgnoreCase)
        || normalized.Contains("this is", StringComparison.OrdinalIgnoreCase)
        || normalized.Contains("can be translated", StringComparison.OrdinalIgnoreCase);
}

private static bool TryUnwrapQuotedLine(string text, out string unwrapped)
{
    unwrapped = string.Empty;
    if (string.IsNullOrWhiteSpace(text))
    {
        return false;
    }

    var trimmed = text.Trim();
    if (trimmed.Length < 2)
    {
        return false;
    }

    var first = trimmed[0];
    var last = trimmed[^1];
    var isQuoted = (first == '“' && last == '”')
        || (first == '「' && last == '」')
        || (first == '『' && last == '』')
        || (first == '"' && last == '"')
        || (first == '\'' && last == '\'')
        || (first == '`' && last == '`');
    if (!isQuoted)
    {
        return false;
    }

    var inner = trimmed.Substring(1, trimmed.Length - 2).Trim();
    if (string.IsNullOrWhiteSpace(inner))
    {
        return false;
    }

    unwrapped = inner;
    return true;
}
```

### 5. `AudioPipelineService.cs`：修复延迟任务取消源 Dispose 竞态

修改原因：

- 旧代码在取消方调用 `Cancel()` 后马上 `Dispose()`。
- 后台 `Task.Delay(..., cts.Token)` 或 `cts.IsCancellationRequested` 仍可能访问同一个 CTS，导致 `ObjectDisposedException`。
- 新逻辑在创建时先保存 `CancellationToken token`，后台任务只读 token；取消方只 Cancel 和置空引用；CTS 由后台任务在 `finally` 中释放。

VAD 片段合并延迟任务修改代码：

```csharp
private void SchedulePendingVadSegmentFlushLocked()
{
    var cts = new CancellationTokenSource();
    var token = cts.Token;
    _pendingVadSegmentFlushCts = cts;

    _ = Task.Run(async () =>
    {
        try
        {
            await Task.Delay(VadSegmentMergeWindow, token).ConfigureAwait(false);

            RecognitionWorkItem? workItem = null;
            lock (_pendingVadSegmentLock)
            {
                if (!ReferenceEquals(_pendingVadSegmentFlushCts, cts) || token.IsCancellationRequested)
                {
                    return;
                }

                _pendingVadSegmentFlushCts = null;
                workItem = TakePendingVadSegmentLocked();
            }

            if (workItem.HasValue)
            {
                QueuePendingVadRecognitionWorkItem(workItem.Value);
            }
        }
        catch (OperationCanceledException)
        {
            // ignored
        }
        finally
        {
            lock (_pendingVadSegmentLock)
            {
                if (ReferenceEquals(_pendingVadSegmentFlushCts, cts))
                {
                    _pendingVadSegmentFlushCts = null;
                }
            }

            cts.Dispose();
        }
    });
}

private void CancelPendingVadSegmentFlushLocked()
{
    if (_pendingVadSegmentFlushCts == null)
    {
        return;
    }

    _pendingVadSegmentFlushCts.Cancel();
    _pendingVadSegmentFlushCts = null;
    _pendingVadSegmentMergeArmed = false;
}
```

Drain disable fallback 延迟任务修改代码：

```csharp
private void ScheduleDrainDisableFallback(TimeSpan? delay = null, bool requireRecognitionQueueEmpty = true)
{
    CancellationTokenSource cts;
    CancellationToken token;
    lock (_drainDisableLock)
    {
        _pendingDrainDisableCts?.Cancel();

        cts = new CancellationTokenSource();
        token = cts.Token;
        _pendingDrainDisableCts = cts;
    }

    _ = Task.Run(async () =>
    {
        try
        {
            await Task.Delay(delay ?? DrainDisableTimeout, token).ConfigureAwait(false);
            if (token.IsCancellationRequested || CurrentState != PipelineState.DisablingAfterSpeech)
            {
                return;
            }

            if (requireRecognitionQueueEmpty && Volatile.Read(ref _pendingRecognitionWorkItems) > 0)
            {
                return;
            }

            DisableRecognitionNow();
        }
        catch (OperationCanceledException)
        {
            // ignored
        }
        finally
        {
            lock (_drainDisableLock)
            {
                if (ReferenceEquals(_pendingDrainDisableCts, cts))
                {
                    _pendingDrainDisableCts = null;
                }
            }

            cts.Dispose();
        }
    });
}

private void CancelPendingDrainDisable()
{
    lock (_drainDisableLock)
    {
        if (_pendingDrainDisableCts == null)
        {
            return;
        }

        _pendingDrainDisableCts.Cancel();
        _pendingDrainDisableCts = null;
    }
}
```
