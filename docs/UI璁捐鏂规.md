# VRCLS UI 设计方案（新版）

> 目标：主窗口即透明 Overlay（带任务栏图标），用于实时展示；“设置窗口”单独弹出，包含所有设置与日志。

## 主窗口（透明 Overlay，任务栏可见）
- 形态：半透明、可拖动、默认置顶，任务栏显示图标和标题，方便最小化/恢复。
- 顶部操作：Mic 开关、Desk 开关、当前监听源指示（Mic/Desk）、“设置”按钮。
- 列表：按时间倒序，最新在上。
  - 左侧竖排标签显示来源（Mic/Desk），用不同颜色区分来源。
  - 每行左右两块：左=原文，右=译文；卡片圆角、轻微阴影，悬浮高亮。
- 交互：
  - 左键拖动（未锁定时）；锁定后鼠标穿透、不可拖动。
  - 置顶/锁定仍由 VM 属性控制（TopMost、Win32 穿透）。
  - “设置”按钮打开设置窗口。

示意（ASCII）：
```
┌──────── VRCLS Overlay (任务栏可见) ────────┐
│ [最小化] [关闭]  Mic: [开/关]  Desk: [开/关]  源: Mic  [设置] │
├────────────────────────────────────────────┤
│ [Mic ] 原文原文原文原文           | 译文译文译文译文  (最新)   │
│ [Desk] 原文原文原文原文          | 译文译文译文译文           │
│ [Mic ] 原文原文原文原文           | 译文译文译文译文           │
│      …（时间倒序，最新在上）                                │
└────────────────────────────────────────────┘
```

## 设置窗口（单独弹窗）
- 触发：主窗口顶部“设置”按钮。
- 页签/分组：
  1) 服务器与鉴权：API IP/Port，用户名/密码（安全输入），Token 状态。
  2) 翻译：源/目标语言、第二/第三目标，默认引擎（服务器优先，本地/第三方可选），Emoji 过滤。
  3) OSC：IP/端口，Chatbox 模板。
  4) 热键/阈值：麦克风/桌面阈值，热键。
  5) 外观：深/浅主题，Overlay 字体/透明度（可选）。
  6) 日志：时间/来源/内容列表，清空/导出。
- 主窗口不再单独呈现控制/设置页，配置与日志集中在此窗口。

## 绑定要点
- 主窗口（Overlay）：
  - 状态：`IsMicListening`、`IsDesktopListening`、`CurrentSource`、`IsOverlayPinned`、`IsOverlayLocked`。
  - 列表：`ObservableCollection` (含 `Source`/`Text`/`Translation`/`Timestamp`/`Color`)，倒序显示。
  - 命令：`ToggleMicCommand`、`ToggleDesktopCommand`、`OpenSettingsCommand`、置顶/锁定/隐藏。
- 设置窗口：
  - 映射 `AppConfig`（服务器/鉴权/翻译/OSC/阈值/热键/外观）。
  - 日志页复用 `Logs`（或独立数据源）。

## 主题
- 继续使用 MaterialDesign 5.x (`MaterialDesign2.Defaults.xaml`)，如需更多样式可合并其他主题资源。
