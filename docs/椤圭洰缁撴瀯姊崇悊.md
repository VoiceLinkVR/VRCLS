# VRCLS-CSharp 代码结构与主流程

## 目录与模块
- `01.VRCLS.Core`：配置与接口。`AppConfig` 描述 API/OSC/语言/TTS 等配置（默认保存在 `%AppData%/VRCLS/config.json`），接口统一声明了音频、VAD、识别、翻译、TTS、OSC、模型路径解析等能力。
- `02.VRCLS.Services`：核心逻辑实现。
  - Audio：`AudioCaptureService`（麦克风/桌面捕获，16k 单声道），`VadService`（silero_vad.onnx 切分语音段），`AudioPipelineService`（通道缓冲+事件分发），`ModelPathResolver`（自动查找 VAD/Sherpa 模型），`OpusCodecService`（编码与打包）。
  - Recognition：`FastApiRecognitionService`（远程 API，登录→Opus→/api/func/multitranslateToOtherLanguage），`SherpaAsrService`（本地识别，模型目录可配置）。
  - Translation：`ServerTranslationService`（后端翻译，优先 /api/func/webtranslate）。
  - External：`OscService`（VRChat OSC，Chatbox/Avatar/Input）。
  - Tts：`SystemSpeechTtsService`（本地 System.Speech，失败则静默）。
- `03.VRCLS.UI`：WPF Overlay 与设置页，MVVM。
  - `App.xaml.cs`：启动/DI/配置读写。
  - `MainViewModel`：创建两条音频管线（Mic、Desktop），绑定 UI 命令与日志、OSC、TTS。
  - `SettingsViewModel`：配置编辑与连通性测试。
  - `Views`：Overlay 主窗与设置窗。
- `tests`：`VRCLS.ConsoleTest`（采集→VAD→远程识别示例）、`VRCLS.BackendSmoke`（登录/识别/翻译/OSC/TTS 冒烟）。

## 运行主链路（麦克风与桌面各一条）
```
启动 App.xaml.cs
  └─ 读取 %AppData%/VRCLS/config.json → 注册 DI → MainWindow+MainViewModel
MainViewModel 初始化
  └─ AudioPipelineFactory.CreatePipeline(source=Mic/Desktop, isLoopback)
       ├─ AudioCaptureService (Mic/Loopback)
       ├─ VadService (可选，silero_vad.onnx)
       └─ Recognition
            • local: SherpaAsrService (需 Sherpa 模型目录)
            • remote: FastApiRecognitionService (登录后发送 Opus)
  └─ 事件回调 TranscriptionResult
       ├─ 若无翻译 → ServerTranslationService 调后端补译
       ├─ 更新 UI（原文/译文/日志/音量/说话态/当前源）
       ├─ OSC Chatbox 发送格式化文本
       ├─ 可复制剪贴板（CopyBox）
       └─ 可调用 SystemSpeech TTS（TtsToggle）
用户命令
  ├─ ToggleMic / ToggleDesktop：开始/停止采集
  ├─ OpenSettings：打开设置窗口并同步设备列表
  ├─ HideOverlay：最小化
  └─ ExportLogs：导出当前日志到 文档/VRCLS/VRCLS-Logs-*.txt
```

## 配置与模型路径要点
- 配置文件默认在 `%AppData%/VRCLS/config.json`；启动与退出时读写。后端地址优先使用 `BaseUrl`（内部自动补 `/api/`），旧的 `ApiIp/ApiPort` 仅作兼容备用。
- 模型自动搜索顺序（示例）：运行目录 `models/` → 仓库根 `02.VRCLS.Services/models/`、`Audio/models/` → `tests/VRCLS.ConsoleTest/models/` → 自定义路径（`AppConfig.VadModelPath`/`SherpaModelDir`）。
- `RecognitionMode=local` 时需准备 Sherpa 模型目录；否则自动回退远程。

## 与后端交互
- 登录：`POST /api/login`，`FastApiRecognitionService` 和 `ServerTranslationService` 内部自动处理 token。
- 语音识别+翻译：`POST /api/func/multitranslateToOtherLanguage`（音频 Opus 包）；翻译回退 `POST /api/func/webtranslate`。
- OSC：`OscService` 直接调用 VRChat OSC Chatbox/Avatar/Input。

## 快速上手检查
- 确认 `%AppData%/VRCLS/config.json` 中 `ApiIp/ApiPort/UserInfo` 与后端一致，必要时设定 `VadModelPath`/`SherpaModelDir`。
- 需要 VRChat OSC 时确认 `osc-port`/`oscServerPort` 未被占用。
- 本地识别模式需放置 Sherpa 模型（如 `sherpa-onnx-streaming-zipformer-bilingual-zh-en-2023-02-20`）。
